## Identity

This repository is not a generic AI tooling project.

It is an exploration into how AI-native operating systems emerge inside modern growth organizations.

The focus is on:
- organizational intelligence systems
- strategic inference layers
- workflow orchestration
- lifecycle decision architectures
- horizontal signal propagation
- operational leverage through AI-native workflows

The objective is not to build isolated tools.

The objective is to study how experienced operator judgment can be codified into scalable systems.

Every inference generated should feel impossible to replicate without domain context shaped through real organizational experience.

## Technical Architecture

### Pipeline

- **Signal Collection** → `signal_collectors/` — RSS, web, manual, API sources
- **Inference Engines** → `inference_engines/` — strategic, organizational, workflow inference
- **Operating Memos** → `operating_memos/` — weekly synthesis generation
- **Strategic Memory** → `strategic_memory/` — SQLite-backed thesis/prediction tracking
- **Narrative Strategy** → `narrative_strategy/` — positioning analysis
- **Workflow Architecture** → `workflow_architecture/` — bottleneck identification & redesign
- **Organizational Models** → `organizational_models/` — org design pattern library
- **Decision Systems** → `decision_systems/` — decision architecture framework

### Key Entry Points

- `python run_pipeline.py` — Full pipeline: collect → infer → memorize → generate memo
- `python run_weekly.py` — Weekly operating memo generation
- `python -m signal_collectors.manual` — Manually submit a signal

### Configuration

- `config/settings.py` — Model routing, API keys, pipeline config
- `config/sources.yaml` — Signal source definitions
